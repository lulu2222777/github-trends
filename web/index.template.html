    这套榜单是怎么算的

    排名不看 star 存量，而是看 增速 × 质量。四个维度先做分位数归一化（避免 star 的长尾分布让头部项目碾压一切），再按 0.42 增量 + 0.23 涨幅 + 0.20 质量 + 0.15 新鲜度 加权合成。

    质量分包含什么

    • 是否开源协议 / 有无正经描述
    • topics 标注是否完整、有官网
    • fork/star 比、issue 活跃度
    • 最近 30 天是否有推送

    数据说明

    • 来源：GitHub 官方 Search API
    • 已过滤清单 / 教程 / 题库类仓库
    • 快照每日追加，用于计算真实增量
